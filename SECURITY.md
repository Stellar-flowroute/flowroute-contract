# Security Policy

## Status

The router contract in this repository is **unaudited**. It runs on Stellar testnet only. Do not use it with real funds on mainnet until a formal security audit has been completed.

## Scope

In scope: the router contract under `contracts/router`.

Out of scope: everything else, including the application layer in the sibling repository `flowroute-app`.

## Reporting a vulnerability

Report security issues privately through GitHub private vulnerability reporting. Open the **Security** tab of this repository and use **Report a vulnerability**. Do not open a public issue for a security problem.
